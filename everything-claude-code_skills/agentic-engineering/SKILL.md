# Agentic Engineering

在 AI Agent 执行大部分实施工作且人类执行质量和风险控制时，使用本技能进行工程工作流。

## 操作原则

1. 在执行前定义完成标准。
2. 将工作分解为 Agent 大小的单元。
3. 按任务复杂度路由模型层级。
4. 使用评估和回归检查进行度量。

## 评估优先循环

1. 定义能力评估和回归评估。
2. 运行基线并捕获失败签名。
3. 执行实施。
4. 重新运行评估并比较增量。

## 任务分解

应用 15 分钟单元规则：
- 每个单元应独立可验证
- 每个单元应具有单一主导风险
- 每个单元应暴露清晰的完成条件

## 模型路由

- Haiku：分类、样板转换、狭窄编辑
- Sonnet：实施和重构
- Opus：架构、根因分析、多文件不变式

## 会话策略

- 对于紧密耦合的单元继续会话。
- 在主要阶段转换后开始新会话。
- 在里程碑完成后压缩，而非正在进行调试期间。

## AI 生成代码的审查重点

优先考虑：
- 不变式和边缘情况
- 错误边界
- 安全和认证假设
- 隐藏耦合和推出风险

当自动 format/lint 已经强制执行样式时，不要在仅样式的分歧上浪费审查周期。

## 成本纪律

追踪每任务：
- 模型
- token 估计
- 重试
- 实际时间
- 成功/失败

仅当较低层级因清晰的推理差距失败时才升级模型层级。
