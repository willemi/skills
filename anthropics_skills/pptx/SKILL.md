## 设计想法

**不要创建无聊的幻灯片。** 纯项目符号的白底背景不会给任何人留下深刻印象。考虑以下列表中的每个幻灯片的想法。

### 开始前

- **选择大胆且与内容相关的配色方案**：调色板应该感觉是为这个主题特意设计的。如果将颜色交换到完全不同的演示文稿中仍然"可行"，说明没有做出足够具体的选择。
- **主导而非平等**：一种颜色应占主导（60-70% 视觉权重），配以 1-2 种辅助色调和一种锐利的强调色。永远不要让所有颜色权重相等。
- **深色/浅色对比**：封面和结论幻灯片使用深色背景，内容幻灯片使用浅色（"三明治"结构）。或者为高级感全程使用深色主题。
- **承诺一种视觉主题**：选择**一个**独特的元素并重复使用——圆形图像框、彩色圆圈中的图标、粗单边边框。在每个幻灯片上保持一致。

### 配色方案

选择与主题匹配的颜色——不要默认为通用的蓝色。使用这些配色方案作为灵感：

| 主题 | 主色 | 次色 | 强调色 |
|-------|---------|-----------|--------|
| **午夜高管** | `1E2761` (海军蓝) | `CADCFC` (冰蓝) | `FFFFFF` (白色) |
| **森林与苔藓** | `2C5F2D` (森林绿) | `97BC62` (苔藓绿) | `F5F5F5` (奶油色) |
| **珊瑚能量** | `F96167` (珊瑚色) | `F9E795` (金色) | `2F3C7E` (海军蓝) |
| **温暖陶土** | `B85042` (陶土色) | `E7E8D1` (沙色) | `A7BEAE` (鼠尾草绿) |
| **海洋渐变** | `065A82` (深蓝) | `1C7293` (绿松石色) | `21295C` (午夜蓝) |
| **炭极简** | `36454F` (炭色) | `F2F2F2` (米白) | `212121` (黑色) |
| **绿松石信任** | `028090` (绿松石色) | `00A896` (海水绿) | `02C39A` (薄荷绿) |
| **浆果与奶油** | `6D2E46` (浆果色) | `A26769` (灰玫瑰色) | `ECE2D0` (奶油色) |
| **鼠尾草宁静** | `84B59F` (鼠尾草绿) | `69A297` (桉树绿) | `50808E` (板岩灰) |
| **樱桃大胆** | `990011` (樱桃色) | `FCF6F5` (米白) | `2F3C7E` (海军蓝) |

### 对于每张幻灯片

**每张幻灯片都需要视觉元素**——图像、图表、图标或形状。只有文本的幻灯片是容易被遗忘的。

**布局选项:**
- 两列（文本在左，插图在右）
- 图标 + 文本行（彩色圆圈中的图标，下方加粗标题，下方描述）
- 2x2 或 2x3 网格（一侧为图像，另一侧为内容块网格）
- 半页图片（全左或全右），内容叠加

**数据显示:**
- 大数字标注（60-72pt 的大数字，下方小标签）
- 对比列（前后、利弊、并排选项）
- 时间线或流程流（编号步骤、箭头）

**视觉润色:**
- 部分标题旁的彩色小圆圈中的图标
- 关键统计数据或标语的斜体强调文本

### 排版

**选择独特的字体搭配**——不要默认为 Arial。选择有特性的标题字体并与简洁的正文字体搭配。

| 标题字体 | 正文字体 |
|-------------|-----------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| Impact | Arial |
| Palatino | Garamond |
| Consolas | Calibri |

| 元素 | 大小 |
|---------|------|
| 幻灯片标题 | 36-44pt 粗体 |
| 章节标题 | 20-24pt 粗体 |
| 正文文本 | 14-16pt |
| 说明文字 | 10-12pt 柔和 |

### 间距

- 0.5" 最小边距
- 内容块之间 0.3-0.5"
- 留出呼吸空间——不要填满每一寸

### 避免（常见错误）

- **不要重复相同的布局**——在各幻灯片变化列、卡片和号召性用语
- **不要居中正文文本**——左对齐段落和列表；仅标题居中
- **不要在尺寸对比上吝啬**——标题需要 36pt+ 才能从 14-16pt 正文中脱颖而出
- **不要默认为蓝色**——选择反映特定主题的颜色
- **不要随机使用间距**——选择 0.3" 或 0.5" 间隙并一致使用
- **不要在一种幻灯片上样式化而其余留白**——完全承诺保持简单或高级
- **不要创建纯文本幻灯片**——添加图像、图标、图表或视觉元素；避免纯标题 + 项目符号
- **不要忘记文本框内边距**——当对齐与形状或图标边缘的线条时，将文本框的 `margin` 设置为 0 或偏移形状以考虑内边距
- **不要使用低对比度元素**——图标**和**文本需要与背景形成强烈对比；避免浅色文本在浅色背景上或深色文本在深色背景上
- **永远不要在标题下使用强调线**——这是 AI 生成幻灯片的标志；使用空白或背景色代替

## 质量保证（必需）

**假设有问题。你的工作是找出它们。**

你的第一个渲染几乎从不是正确的。将质量保证视为缺陷搜索，而不是确认步骤。如果第一次检查就没发现问题，说明检查得不够认真。

### 内容质量保证

```bash
python -m markitdown output.pptx
```

检查缺失内容、拼写错误、错误顺序。

**使用模板时，检查遗留的占位符文本：**

```bash
python -m markitdown output.pptx | grep -iE "xxxx|lorem|ipsum|this.*(page|slide).*layout"
```

如果 grep 返回结果，在宣布成功前修复它们。

### 视觉质量保证

**⚠️ 使用子代理**——即使只有 2-3 张幻灯片。你已经盯着代码看，会看到预期的内容，而不是实际的内容。子代理有新鲜的眼光。

将幻灯片转换为图像（参阅[转换为图像](#转换为-to-images)），然后使用此提示：

```
直观检查这些幻灯片。假设有问题——找出它们。

寻找：
- 重叠元素（文字穿过形状，线条穿过文字，堆叠元素）
- 文本溢出或在边缘/框边界处被切断
- 为单行文本定位但标题换两行的装饰线
- 来源引用或页脚与上方内容碰撞
- 元素太近（< 0.3" 间隙）或卡片/部分几乎接触
- 间隙不均匀（一处大空区，另一处拥挤）
- 与幻灯片边缘的距离不足（< 0.5"）
- 列或类似元素没有一致对齐
- 低对比度文本（例如浅灰色文本在奶油色背景上）
- 低对比度图标（例如深色图标在深色背景上没有对比圆圈）
- 文本框太窄导致过多的换行
- 遗留的占位符内容

对于每张幻灯片，列出问题或关切区域，即使是很小的。
```

读取和分析这些图像：
1. /path/to/slide-01.jpg（预期：[简要描述]）
2. /path/to/slide-02.jpg（预期：[简要描述]）

报告**所有**发现的问题，包括微小问题。

### 验证循环

1. 生成幻灯片 → 转换为图像 → 检查
2. **列出发现的问题**（如果没发现，更批判性地再看一次）
3. 修复问题
4. **重新验证受影响的幻灯片**——一个修复经常创造另一个问题
5. 重复直到完整通过不出现新问题

**在至少完成一次修复-验证周期之前不要宣布成功。**

## 转换为图像

将演示文稿转换为独立的幻灯片图像以供视觉检查：

```bash
python scripts/office/soffice.py --headless --convert-to pdf output.pptx
pdftoppm -jpeg -r 150 output.pdf slide
```

这将创建 `slide-01.jpg`、`slide-02.jpg` 等。

要在修复后重新渲染特定幻灯片：

```bash
pdftoppm -jpeg -r 150 -f N -l N output.pdf slide-fixed
```
